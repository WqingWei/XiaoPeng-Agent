### 1.6 初始化前端 Next.js 项目 ✅

**执行命令**：
```bash
npx create-next-app@latest frontend --typescript --tailwind --eslint --app --src-dir --import-alias "@/*" --use-pnpm --yes
```

**前置操作**：pnpm 未预装，通过 `npm install -g pnpm` 安装了 pnpm v11.20.0。

**实际安装版本**：

| 技术 | 计划版本 | 实际安装版本 |
|------|---------|------------|
| Next.js | 14.x | **16.3.0** |
| React | 18.x | **19.2.8** |
| TypeScript | 5.x | **5.9.3** |
| Tailwind CSS | 3.x | **4.3.3** |
| pnpm | — | **11.20.0** |

> **版本差异说明**：Next.js 16 + React 19 + Tailwind v4 是当前最新版本，与计划的 14.x 存在大版本差异。主要影响：
> - Tailwind v4 的配置方式不同（使用 CSS-first 配置，不再需要 `tailwind.config.ts`）
> - React 19 移除了部分废弃 API
> - shadcn/ui 已适配 Tailwind v4（初始化时自动检测）
> - 所有功能向后兼容，不影响开发
