- 所有数据模型以 JSON Schema 形式在文档中统一定义，字段命名采用驼峰式并附带类型注释
- 安全规则采用分级体系（L0-L4）与硬/软规则二分法，每条规则包含 rule_id、触发条件、动作模板和升级策略
- Agent 输出强制遵循固定 JSON 结构，包含 user_response、service_plan、reasoning、forbidden_actions、safety_alerts、follow_up 六个必填字段
- 工具调用采用 tool_id + params 的原子化定义方式，每个工具明确标注参数与安全约束
- 场景描述统一采用「输入信号 → Agent 决策流程 → 输出要求」三段式结构，便于评审对照
