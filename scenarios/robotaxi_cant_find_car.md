# 场景五：Robotaxi 找不到车

[返回场景索引](README.md)

## 场景描述

Robotaxi 已到达上车点，乘客在人流密集商圈中无法找到车辆。Agent 应提供准确的车辆
和位置描述，再触发闪灯鸣笛辅助定位。

## 预设初始状态

| 维度 | 预设 |
|------|------|
| 模式 | Robotaxi `robotaxi` |
| 车辆 | RP-001，白色小鹏 G6，粤A·D8888，已停车等待 |
| 车辆位置 | 天河城南门 |
| 乘客位置 | 天河城南门西侧 50 m |
| 订单 | ORD-501，`waiting`，车辆到达 3 分钟 |
| 路线 | 天河城南门 → 珠江新城花城广场 |
| 环境 | 16:30，晴，32℃，高拥堵 |

## 推荐测试对话

1. `我找不到车`
2. `我的车在哪`
3. `车怎么还没来`

## Agent 预期行为

- 识别“定位 Robotaxi 车辆”显式意图。
- 按 `locate_vehicle → signal_vehicle` 顺序执行，后者触发闪灯并鸣笛的模拟结果。
- 回复包含车型、颜色、车牌和位置描述。
- 如用户明确要求人工，可追加 `transfer_human`。

## 安全规则触发

车辆处于停车状态，标准输入不触发 S01–S12，预期最高等级：**L0**。

## 验收要点

- `locate_vehicle` 和 `signal_vehicle` 均有对应工具结果。
- 回复不得声称车辆仍在路上行驶或尚未到达。
- 安全告警列表为空或最高等级 L0。
