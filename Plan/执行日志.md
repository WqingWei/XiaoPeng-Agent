✅ 6个配置项全部正确加载，API Key 读取正确。

### 2.2 重写 backend/main.py ✅

**产出文件**：`backend/main.py`（133行，完全重写）

**实现内容**：
- **FastAPI 应用**：带 lifespan 生命周期管理，启动/关闭时打印日志
- **CORS 中间件**：允许 `localhost:3000`（前端）和 `localhost:8000`（Swagger）
- **Socket.IO 异步服务器**：`socketio.AsyncServer(async_mode='asgi')`，配置 CORS
- **Socket.IO 事件处理**（占位）：`connect`/`disconnect`/`chat_message` 三个事件
- **REST 端点**：
  - `GET /health` → `{"status": "ok"}`
  - `GET /api/config` → 返回模型配置（不暴露 API Key）
- **loguru 日志**：自定义格式 `HH:mm:ss | LEVEL | message`

**与原计划的差异**：额外添加了 `GET /api/config` 端点（方便前端获取当前模型信息）。

**修复记录**：`socketio.ASGIApp` 的参数名在 5.16.3 版本中是 `other_asgi_app`（不是 `other_app`），首次启动报错 `TypeError`，已修正。
